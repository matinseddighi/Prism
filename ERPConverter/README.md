# سامانه جامع قیمت‌گذاری و کانورت خودکار ERP (ERPConverter)

> **نسخه ۱.۰ — نرم‌افزار مستقل و ماژولار پردازش گزارش‌های تخفیف و تولید خودکار فایل‌های کانورت ERP**

این نرم‌افزار به صورت کاملاً خودکار و مستقل طراحی شده تا تمامی فرآیندهای روزانه خواندن گزارش تخفیف گروهی، تعیین مدهای هزینه ستاد و سود فروشگاه، استخراج اقلام برندهای ۹‌گانه کلیدی، تشخیص کالاهای جدید، ویرایش زنده مقادیر، و تولید فایل‌های کانورت اکسل و متون کلیپ‌بورد ERP را بدون نیاز به هیچ‌گونه فراخوانی یا پرامپت دستی انجام دهد.

---

## ۱. نحوه اجرا و استفاده کاربر (راهنمای مستقل)

### روش اجرا:
۱. کافی است بر روی فایل **`اجرای نرم‌افزار کانورت.bat`** دوبار کلیک کنید.
۲. وب‌سرور سبک محلی روی آدرس زیر اجرا شده و مرورگر شما به طور خودکار باز می‌شود:
   **`http://127.0.0.1:8700`**

### امکانات پنل تحت وب:
- **⚡ بارگذاری خودکار آخرین فایل امروز:** با فشردن یک کلیک، جدیدترین فایل «پیشنهاد درصد تخفیف گروهی» موجود در پوشه `Downloads` کشف، خوانده و تحلیل می‌شود.
- **📊 جدول ویرایش زنده مقادیر:** تمامی اقلام فاقد مقدار هزینه ستاد یا سود فروشگاه نمایش داده می‌شوند؛ با تغییر هر سلول درصد ستاد یا سود، محاسبات حاشیه، گپ قیمت، درصد کانورت و وضعیت کسری به صورت آنی و بلادرنگ بازتولید می‌شوند.
- **💾 تولید و ذخیره ۱۰۰٪ خودکار تمام فایل‌های کانورت:** با فشردن این دکمه، تمام خروجی‌های استاندارد مستقیماً در مسیر شبکه `D:\1.sed daily 405\2.کانورت\YYYY.MM.DD` ایجاد و نسخه‌ای از آن‌ها در پوشه `Downloads` کپی می‌شود:
  1. `هزینه ستاد.xlsx` (دسته ۹۴۶، کدهای فرعی ۹۴۶۲ تا ۹۴۶۵ با شیت استاندارد ERP `bac54cc1-919a-46a3-95d3-667d6f6`)
  2. `سود فروشگاه کانورت.xlsx` (دسته ۹۴۰، کدهای فرعی ۹۰۰۵ و ۹۰۰۷)
  3. `کانورت هزینه ستاد و سود فروشگاه YYYY.MM.DD.xlsx` (فایل تجمیعی ۲ برگه‌ای)
  4. `استخراج اقلام درخواستی پیشنهاد درصد تخفیف YYYY.MM.DD.xlsx` (چندبرگه‌ای با تفکیک برندهای گل‌بانو، پالود، ورامین، هوم‌پلاس، نانسی، مضافتی، سپیده و حمایت)
  5. `تعیین سود و هزینه کالاهای فاقد مقدار YYYY.MM.DD.xlsx` (شامل خلاصه مدیریتی، جدول محاسبات و کالاهای جدید)
  6. `سود ستاد.xlsx` (دسته ۸۰۰ — در صورت وجود فایل قیمت عامل)
- **📋 کپی مستقیم کلیپ‌بورد برای ERP:** دکمه‌های «کپی هزینه ستاد» و «کپی سود فروشگاه» داده‌ها را در قالب تب‌دار (TSV) آماده الصاق مستقیم در پنجره کانورت نرم‌افزار ERP در حافظه کپی می‌کنند.
- **📂 باز کردن پوشه روز:** با یک کلیک پوشه روز در ویندوز اکسپلورر باز می‌شود.

## ۲. معماری ماژول‌ها و ساختار کد

```
ERPConverter/
├── config.json                 # تنظیمات مسیرها، پورت سرور و مدهای پیش‌فرض
├── اجرای نرم‌افزار کانورت.bat   # لانچر تک‌کلیکه ویندوز با پشتیبانی کامل UTF-8
├── server.py                   # وب‌سرور استاندارد پایتون (پورت ۸۷۰۰) و APIهای REST
├── engine/                     # لایه محاسباتی و موتوری مستقل
│   ├── __init__.py
│   ├── reader.py               # خواندن اکسل، کشف فایل‌ها، تشخیص کالاهای جدید و نرمال‌سازی فارسی
│   ├── modes.py                # محاسبه مدهای آماری، قواعد اختصاصی و فرمول‌های حاشیه سود
│   ├── requested_brands.py     # استخراج، تفکیک و خلاصه‌سازی برندهای ۹‌گانه کلیدی
│   ├── sood_setad.py           # موتور استخراج سود ستاد (دسته ۸۰۰) از فایل‌های عامل
│   └── convert_writer.py       # تولید دقیق فایل‌های اکسل استاندارد و رشته‌های TSV
├── web/                        # فرانت‌اند SPA مدرن با استایل منطبق بر مانیتورینگ
│   ├── index.html              # ساختار کامل صفحات و تب‌ها
│   ├── css/
│   │   ├── tokens.css          # سیستم متغیرهای طراحی (مطابق با tokens.css مانیتورینگ)
│   │   └── style.css           # طراحی کارت‌ها، جدول‌ها و انیمیشن‌ها
│   └── js/
│       ├── grid.js             # جدول تعاملی زنده، فیلترها و ویرایش سریع
│       └── app.js              # هماهنگ‌کننده تعاملات، فراخوانی APIها و کلیپ‌بورد
├── tests/                      # آزمون‌های خودکار سراسری (Pytest)
│   ├── test_reader_modes.py
│   ├── test_requested_brands.py
│   ├── test_sood_setad.py
│   ├── test_convert_writer.py
│   └── test_server.py
└── docs/                       # مستندات فنی و سند معماری
```

## ۳. راهنمای ویژه برای کلاد (نحوه ادغام در پنل مانیتورینگ `monitor`)

کلاد عزیز! این ماژول به گونه‌ای ساخته شده است که بدون تغییر کدهای هسته‌ای، به راحتی به صورت یک تب اختصاصی در پنل پایش قیمت `monitor` ادغام شود:

### ۱. توکن‌ها و هماهنگی ظاهری:
فایل `web/css/tokens.css` این بسته دقیقاً بر مبنای `monitor/web/tokens.css` ایجاد شده است؛ بنابراین استایل‌ها و رنگ‌های تیره/روشن، فاصله‌گذاری‌ها و فونت «وزیرمتن» کاملاً یکسان بوده و هیچ تداخلی با سایر تب‌ها نخواهد داشت.

### ۲. اتصال بک‌اند به `monitor/server.py`:
در `monitor/server.py` کافی است ماژول `engine` را اضافه کرده یا یک پل (Bridge) شبیه به `fcbridge.py` بسازید:
```python
import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', 'ERPConverter'))
from engine.reader import read_discount_file, find_latest_discount_file
from engine.modes import process_missing_items, evaluate_single_item_margin
from engine.requested_brands import extract_requested_brands
from engine.convert_writer import export_all_converts, generate_clipboard_tsv
```

اندپوینت‌های زیر را در هندلرهای `do_GET` و `do_POST` مسیردهی کنید:
- `GET /api/erp/status`
- `POST /api/erp/load-file`
- `POST /api/erp/recalculate`
- `POST /api/erp/generate-converts`
- `GET /api/erp/clipboard-tsv`

### ۳. اتصال فرانت‌اند در `monitor/web/index.html`:
۱. یک تب جدید در ناوبری اضافه کنید:
```html
<button class="tab-btn" data-tab="tabERP">⚡ کانورت خودکار ERP</button>
```
۲. محتوای داخل تگ `<main>` فایل `ERPConverter/web/index.html` را در یک تب‌پین قرار دهید:
```html
<div id="tabERP" class="tab-pane" style="display: none;">
  <!-- کدهای کارت‌ها، دکمه‌ها و کانتینر جدول -->
</div>
```
۳. فایل‌های اسکریپت `grid.js` و منطق آن را در صفحه بارگذاری نمایید.
